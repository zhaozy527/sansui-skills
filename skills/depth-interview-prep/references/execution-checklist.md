# 访谈执行检查单

> 访谈中参考用，随访谈大纲产出时附出。
> 来源：《深度访谈方法论》第 13-15 页

## 三个层次

### 态度层 — 价值中立但表达共情
- [ ] 问题出发点中立，不预设立场，不引导用户
- [ ] 给予"人性化"回应：理解、共情用户的需求点和痛点，给用户正向反馈
- [ ] 不追求绝对的"客观""中立"，与受访者共情

### 信息层 — 关注言论之外
- [ ] 除言论外，关注表情、肢体语言、语气
- [ ] 通过反复询问，获得用户真实的想法

### 策略层 — 及时复盘，随时调整
- [ ] 访谈前期及时整理记录、复盘
- [ ] 记录用户之间的核心差异点
- [ ] 标记哪些问题有价值、哪些赘余
- [ ] 随时调整招募要求和访谈大纲

## 场景应对速查

| 场景 | ❌ 不好 | ✅ 更好 |
|---|---|---|
| 问操作细节 | 纯询问"你是怎么做的？" | 邀请共享屏幕操作"可以帮我还原一下当时的使用情况吗？怎么进来的？为什么点击这里？点击后遇到了什么问题？" |
| 用户不认同某功能 | 尝试说服用户"你可能还不太了解…" | 倾听并追问"为什么这么说？具体哪里让你这样觉得？对你有什么影响？" |
| 用户跑题 | 生硬打断"这个偏题了" | 保持倾听后巧妙转移"那我们先聊下 XXX 吧" |
| 用户表面附和 | 直接结束话题"很好，我们也这么觉得" | 下钻原因"为什么这么说？你具体是怎么用的？为什么觉得好？" |

## 停止条件 — 信息量饱和三条件

全部满足时停止访谈：

1. [ ] 找到影响调研问题解答差异的核心维度
2. [ ] 核心维度的各个枚举都有样本覆盖
3. [ ] 可用一句话总结调研发现：
   > "对 XXX（调研问题）的反馈主要因 YY（核心维度）而不同"
   > - Y1 类用户，因 Z1，而选择 X1
   > - Y2 类用户，因 Z2，而选择 X2
