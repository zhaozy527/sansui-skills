# 招募矩阵模板

> 三维度多元招募：人口属性 + 业务属性 + 产品特征属性
> 目的不在样本量，而在覆盖各种用户类型（多元）且信息饱和

## 维度拆解

### 人口属性
| 枚举 | 说明 | 配额 |
|------|------|------|
| {如：性别} | 男/女 | 各 N |
| {如：年龄} | {区间} | {N} |
| {如：城市} | {城市线级} | {N} |

### 业务属性
| 枚举 | 说明 | 配额 |
|------|------|------|
| {如：岗位} | {岗位类型} | {N} |
| {如：职级} | {层级} | {N} |
| {如：入职时长} | {时长区间} | {N} |

### 产品特征属性
| 枚举 | 说明 | 配额 |
|------|------|------|
| {如：使用频率} | 高/中/低 | 各 N |
| {如：使用场景} | {场景类型} | {N} |
| {如：使用原因} | {动机类型} | {N} |

## 招募配额汇总
