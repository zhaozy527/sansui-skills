# social-cast: 社交分享卡片

把你的碎片想法变成一张可以发出去的图。内容进去，带水印的 PNG 出来。

## 参数

| 参数 | 模式 | 尺寸 | 说明 |
|------|------|------|------|
| `-c`（默认） | 内容卡片 | 1080 x auto | 结构化长内容，自动撑高，适合公众号正文配图 |
| `-s` | 短句卡片 | 1080 x 1440 | 单句金句/核心观点，大字排版，适合朋友圈 |
| `-q` | 问答卡片 | 1080 x auto | Q&A 互动格式，问题+回答，适合公众号互动素材 |

## 约束

本 skill 输出为视觉文件（PNG），不适用 Markdown 和 ASCII-only 规范。

## 水印

所有卡片底部固定水印：**zzy** + 当天日期（格式：YYYY.MM.DD）。

## 执行步骤

### 步骤 1：获取日期

```bash
date +%Y.%m.%d
```

记录为 `DATE_STR`。

### 步骤 2：理解内容

分析用户给出的内容：

- 如果是**原始碎片**（随手记的想法、口语化的文字）：先整理成适合分享的结构化表达——提炼核心观点、去掉冗余、但不改变原意。整理后的内容需要让读者一眼抓住重点。
- 如果是**已有结构**（笔记段落、文章片段）：保持结构，精简措辞，突出可读性。
- 如果是**单句金句**：直接用，不做多余加工。

**原则**：尊重原文思想，只做编辑不做创作。不添加用户没说的内容。

### 步骤 3：选择色调

根据内容气质选择背景色和强调色：

| 内容气质 | 背景色 BG_COLOR | 强调色 ACCENT_COLOR |
|----------|-----------------|---------------------|
| 沉稳/思考 | #FAFAF8 | #B8860B |
| 温暖/生活 | #FFF8F0 | #C8702A |
| 科技/理性 | #F5F7FA | #4A7C8A |
| 自然/平和 | #F5F8F0 | #5A8B5A |
| 果断/力量 | #F8F5F2 | #8B4513 |
| 清新/灵感 | #F8FAF8 | #6B8E6B |

如果内容明显不属于以上分类，可以自主选择，但必须遵循：
- 背景色必须是极浅的暖灰或冷灰（接近白但不纯白）
- 强调色饱和度 < 60%，与背景和谐
- 禁止纯黑 #000000、禁止紫色、禁止霓虹色

### 步骤 4：根据模式生成 HTML

#### -c（默认）：内容卡片

模板：`assets/card_template.html`

替换规则：
1. `{{BG_COLOR}}` → 背景色
2. `{{ACCENT_COLOR}}` → 强调色
3. `{{DATE_STR}}` → 日期字符串
4. `{{HEADER}}` → 标题区域 HTML：`<div class="header"><h1>标题文字</h1></div>`
5. `{{BODY_HTML}}` → 正文 HTML

正文 HTML 转换规则：
- 用户内容中的标题 → `<h2>` 标签
- 段落文字 → `<p>` 标签
- 重点句/核心引用 → `<div class="highlight">文字</div>`
- 列表项 → `<ul><li>` 或 `<ol><li>`
- 表格 → `<table>` 标签
- 分隔线 → `<div class="divider"></div>`

#### -s：短句卡片

模板：`assets/short_template.html`

替换规则：
1. `{{BG_COLOR}}` → 背景色
2. `{{ACCENT_COLOR}}` → 强调色
3. `{{DATE_STR}}` → 日期字符串
4. `{{MAIN_TEXT}}` → 核心金句（大字排版）
5. `{{SUB_TEXT}}` → 补充说明（可选，留空则不显示）

#### -q：问答卡片

模板：`assets/qa_template.html`

替换规则：
1. `{{BG_COLOR}}` → 背景色
2. `{{ACCENT_COLOR}}` → 强调色
3. `{{DATE_STR}}` → 日期字符串
4. `{{QUESTION}}` → 问题文字
5. `{{ANSWER_HTML}}` → 回答内容 HTML

### 步骤 5：截图

```bash
node assets/capture.js <html_path> <output_path> 1080 <height> fullpage
```

- 内容卡片（-c）：使用 `fullpage` 参数，高度自动撑开
- 短句卡片（-s）：固定 1080 x 1440，不用 fullpage
- 问答卡片（-q）：使用 `fullpage` 参数，高度自动撑开

**从 skill 根目录运行**：`cd ~/.claude/skills/social-cast && node assets/capture.js ...`

### 步骤 6：交付

1. 输出文件保存到 `~/Downloads/` 目录
2. 文件命名：`{name}_{YYYYMMDD}.png`，name 从内容核心提取（中文直接用，去标点，≤ 15 字符）
3. 报告文件路径，用户可以直接找到并发送

## 质量底线

- 字体：标题用 Noto Serif SC，正文用 Noto Sans SC
- 正文不用纯黑，用 #2A2A2E
- 禁止 Inter 字体
- 行距 ≥ 1.7，段距 ≥ 28px
- 水印必须清晰可见但不抢眼（用 #9A9AA0 灰色）
- 间距数学精确，对齐严格
